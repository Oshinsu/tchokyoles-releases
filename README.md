# Tchok Yoles : les fichiers du jeu

Course et combat de yoles rondes en Martinique, avec un mode carrière de gestion de club. Gratuit, sans compte, sans publicité.

Le site, les guides d'installation et les questions : **https://tchokyoles.com**

| Plateforme | Dernière version | Guide |
|---|---|---|
| Android 10 ou plus (64 bits) | https://tchokyoles.com/download/android | https://tchokyoles.com/installer-android |
| Windows 10 ou 11 (64 bits) | https://tchokyoles.com/download/windows | https://tchokyoles.com/installer-windows |

Chaque version publiée ici donne l'empreinte SHA-256 de son fichier. Au premier lancement, Android (Play Protect) et Windows (SmartScreen) peuvent afficher un avertissement : les guides expliquent quoi faire.

Ce dépôt ne contient que les fichiers à télécharger, pas le code du jeu.
