# Tchok Yoles : les fichiers à télécharger

Course et combat de yoles rondes en Martinique, avec un mode carrière de gestion de club. Bêta gratuite, sans compte, sans publicité.

Le site, les guides d'installation et les questions : **https://tchokyoles.com**

| Plateforme | Fichier | Guide |
|---|---|---|
| Android 10 ou plus (64 bits) | [TchokYoles-0.71.0-android-arm64.apk](https://github.com/Oshinsu/tchokyoles-releases/releases/tag/v0.71.0) | https://tchokyoles.com/installer-android |
| Windows 10 ou 11 (64 bits) | [TchokYoles-0.71.0-windows.zip](https://github.com/Oshinsu/tchokyoles-releases/releases/tag/windows-v0.71.0) | https://tchokyoles.com/installer-windows |

Chaque release donne l'empreinte SHA-256 de son fichier. Le jeu n'est pas signé numériquement : Android et Windows peuvent afficher un avertissement, les guides expliquent quoi faire.

Ce dépôt ne contient que les fichiers à télécharger, pas le code du jeu.
